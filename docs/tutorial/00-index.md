# PitchCoach 教學文件：導覽

**PitchCoach（音準練習教練）** 是給兒童小提琴、長笛學生用的 iOS App：自行實作的即時調音器、長音與音階練習、跟著伴奏的歌唱練習，以及練習紀錄、30 天趨勢與給老師的 PDF 週報。

這套文件從程式設計與系統分析的角度，記錄這個專案「為什麼這樣做」：需求怎麼被轉成可驗收的規則、架構怎麼切、演算法怎麼達到精度要求、哪些地方踩過坑。讀者設定為專案擁有者本人，在開發結束一段時間後回來閱讀，所以不解釋基礎語法，篇幅留給設計意圖、取捨與可以帶走的技巧。

**技術棧**：Swift 6.4、SwiftUI、AVAudioEngine、Accelerate（vDSP）、SwiftData、Swift Charts、Swift Testing／XCTest、GitHub Actions；iOS 17+；零第三方套件。

**文件對應版本**：commit `b7df56a`（2026-10-23）
